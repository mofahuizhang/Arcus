# 内核旋钮架构

单主体大模型内核的架构规范。2026-10-20 定稿，副题「营造法式」。

> 一句话：Arcus 是单主体架构，由基座集合（算力栈与安全价值对齐基座）、模块集两部分组成；路由不单设一层，而是一份约定，集成于二者之中。

## 讲什么

八卷：总图与部件／基材／构件类型与准入／路由约定与调度／刻度与调准／最小可搭单元与八问／与其他标准的接口／不适用范围与免责。每卷末附验收判据，可逐条判定「做到了没有」。

架构之要，在「硬约束不可取消、其松紧与权重可连续调节」——书中称「约束混合」，与「专家的混合」相对。旋钮给的是刻度，不是开关：调准所消去的未定，就是互信息的增量；所付的代价，即拧动成本与错误机会成本。

## 名字

书名作《内核旋钮架构》。「Arcus」是架构的定名，不入书名，正文中仍用：

- 它是这套架构的专名，正文凡指整套架构处皆称 Arcus；
- 书名去专名，是为登记时标题短、且不与商标混淆。

## 与他三件的关系

| 简称 | 书名 | 关系 |

| 《协议》 | MCP 控制层协议规范 | 模块之间怎么连，本书不论 |

本书只声明接口，不定义下游内容；下游只引本书编号，不复制本书定义。
